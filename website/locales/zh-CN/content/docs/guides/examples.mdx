使用已安装 CLI 附带的模板创建新应用。模板会先创建项目，然后再进行验证或运行：

| 模板 | 用途 |
| --- | --- |
| `http` | Fetch 风格 HTTP 服务；推荐的默认选项。 |
| `worker` | 包含一个具名 Queue 处理程序的服务。 |
| `mcp` | 具有输入验证的隔离 MCP stdio 工具。 |
| `minimal` | 用于自定义应用结构的最小 Fetch 处理程序。 |

```sh
tysel init my-service --template http --yes
cd my-service
tysel task verify
tysel dev
```

可将 `http` 替换为 `worker`、`mcp` 或 `minimal`。使用 `tysel run` 运行 Worker；使用 `tysel mcp` 启动 MCP stdio 传输。包、清单格式、测试和现有项目选项请参阅 [`tysel init` 参考](/reference/cli/project#tysel-init)。

下面是起始模板以外各项能力的完整参考应用。下载与已安装 Tysel 版本匹配的源码归档，然后进入所需示例：

```sh
version="$(tysel --version | awk '{print $2}')"
curl -fsSL "https://github.com/wangcch/tysel/archive/refs/tags/v${version}.tar.gz" | tar -xz
cd "tysel-${version}/examples/hello-service"
```

将 `hello-service` 替换为本页列出的其他示例目录。该命令下载版本匹配的应用源码，无需 fork、克隆仓库、构建 Tysel 或覆盖工作进程路径。Wasm Component 使用版本匹配的起始项目包。Postgres、LLM 和 MCP 示例需要 README 中说明的额外环境配置。
