持久处理程序可以暂停执行、经受进程重启，并在恢复时避免重复已完成的工作。你仍然编写普通的 `async` 函数；Tysel 会保存从显式持久边界继续执行所需的状态。

## 定义并启动处理程序

```ts
import type { DurableContext, TyselApp } from "@tysel/types";
import type { TyselEnv } from "../tysel-env.js";

const approvalFlow = async (
  ctx: DurableContext,
  input: { orderId: string },
) => {
  const order = await ctx.step("load-order", () => loadOrder(input.orderId));
  const draft = await ctx.effect("create-draft", () => createDraft(order));

  await ctx.sleep("10m");
  const decision = await ctx.waitForSignal<{ approved: boolean }>("approval");

  return { draft, approved: decision.approved };
};

export default {
  durable: { approvalFlow },
  async fetch(request, runtime) {
    const started = runtime.durable.start("approvalFlow", {
      orderId: new URL(request.url).searchParams.get("orderId")!,
    });
    return Response.json(started, { status: 202 });
  },
} satisfies TyselApp<TyselEnv>;
```

由 `tysel init` 创建的类型化项目已经包含 `tysel-env.d.ts`。修改持久存储或其他清单能力后，请运行 `tysel types`。

`tysel.durable.start` 返回任务 ID，以及已完成或已暂停的状态。可通过 `tysel.durable.sendSignal(taskId, "approval", payload)` 发送外部事件。

## 持久边界

| API | 用途 |
| --- | --- |
| `ctx.step(name, operation)` | 记录确定性计算的结果。 |
| `ctx.effect(name, operation)` | 记录外部副作用的结果。 |
| `ctx.sleep(duration)` | 保存唤醒时间并释放执行资源。 |
| `ctx.waitForSignal(name)` | 暂停，直至指定名称的信号被保存。 |
| `ctx.retry(policy, operation)` | 记录有次数上限的尝试和延迟。 |
| `ctx.now()` | 返回回放安全的时间值。 |
| `ctx.random()` | 返回回放安全的随机值。 |

持久边界必须按顺序 `await`。输入、信号载荷和结果必须可序列化为 JSON，且大小不得超过 1 MiB。

## 回放模型

任务恢复时，Tysel 会从头运行处理程序，并使用已保存的历史。已完成的具名边界直接返回其记录结果。只有当已记录的历史全部消费完毕后，新代码才会运行。

因此：

- 将外部调用和写操作放入 `effect`；
- 为边界使用稳定且含义明确的名称；
- 不要依据环境时间或随机数进行分支，请使用 `ctx.now()` 和 `ctx.random()`；
- 保持现有边界顺序与正在执行的任务兼容；
- 如果外部系统支持，应让下游副作用具有幂等性。

持久执行可以防止 Tysel 有意重复一个已经完成并记录的副作用，但无法与任意外部服务建立原子事务。如果网络故障可能发生在外部提交与本地历史持久化之间，请使用提供商的幂等键。

## 存储

SQLite 是默认的持久存储：

```toml
[durable]
store = "sqlite"
path = "./data/tysel.db"
```

该存储属于运行状态。请进行备份、按敏感数据加以保护，并为相对路径设置明确的工作目录。不要让两个独立调度器同时使用同一个 SQLite 文件。恢复指南请参阅[生产运维](/docs/operations/production)，完整的重启与信号流程请参阅[持久智能体示例](https://github.com/wangcch/tysel/tree/main/examples/durable-agent)。
