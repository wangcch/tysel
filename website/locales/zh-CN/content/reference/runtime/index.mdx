Tysel 应用导出处理程序并使用浏览器风格的全局对象。HTTP 处理程序通过第二个参数接收 Tysel 能力宿主；为兼容旧代码和非 HTTP 处理程序，`globalThis.tysel` 仍然可用。`@tysel/types` 为编辑器和静态检查提供公开声明；它不会安装 JavaScript polyfill。

```ts
import type { TyselApp } from "@tysel/types";

const app = {
  async fetch(request, runtime) {
    return new Response(`isolate ${runtime.isolateId} received ${request.method}`);
  },
} satisfies TyselApp;

export default app;
```

## 稳定性边界

公开应用代码应只使用：

- 此处描述的默认应用导出；
- 兼容性清单中列出的 Web 全局对象；
- `@tysel/types` 声明的 `globalThis.tysel` 成员；
- 测试模块中为 `@tysel/test` 记录的导出。

以下划线开头的宿主钩子，以及来自内部运行时文件的导入，都不属于公开约定。`@tysel/types` 中的声明描述可接受的 TypeScript 结构；实际可用性仍取决于执行配置、清单授权和宿主配置。

这三项可用性检查请参阅[能力矩阵](/docs/capabilities)，固定载荷边界请参阅[限额与默认值](/reference/limits-and-defaults)。
