## 当前版本的最终依据

本参考描述生成这些文档的源码树。对于已安装的二进制文件，其帮助和附带 schema 是最终依据：

```sh
tysel --version
tysel --help
tysel config schema
tysel config show --format json
tysel inspect
```

未知清单字段会导致错误。这里没有列出的 API 或环境变量应视为实现细节，除非发布说明明确将其提升为公开约定。
