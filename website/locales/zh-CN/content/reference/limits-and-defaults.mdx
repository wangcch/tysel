本页汇总分散在清单、协议和宿主实现中的限额。清单值属于配置约定。标记为**实现边界**的条目描述当前运行时，未来版本可能调整；应用应能处理拒绝情况，不能依赖精确上限。

## 应用默认值

| 设置 | 默认值 | 来源 |
| --- | ---: | --- |
| 监听地址 | `127.0.0.1:3000` | `server.listen` |
| HTTP/1.1 / HTTP/2 / WebSocket | 开 / 关 / 关 | `server` |
| 内存 | 128 MiB | `limits.memory_mb` |
| 每轮 JavaScript 的 CPU 时间 | 50 ms | `limits.cpu_ms_per_turn` |
| 请求超时 | 30,000 ms | `limits.request_timeout_ms` |
| 并发 HTTP 请求数 | 1,000 | `limits.max_in_flight` |
| 请求/响应目标大小 | 16 MiB / 16 MiB | `limits.max_request_mb`、`max_response_mb` |
| 应用 SQLite 路径 | `./data/tysel.db` | `durable.path` |
| 测试超时 | 5,000 ms | `tysel test --timeout-ms` |

单位和验证规则请参阅[清单限额](/reference/manifest/limits)。当前运行时会强制实施 `max_request_mb`、`max_response_mb` 和 `max_in_flight`。缓冲响应超过限额时会在发送响应头之前失败；流式响应的累计正文大小一旦超过限额就会中止。

## 网络与执行配置边界

| 接口项 | 当前实现边界 |
| --- | ---: |
| 出站 `fetch` 正文 | 16 MiB |
| 出站重定向次数 | 20 |
| `isolated` 执行配置 HTTP 正文 | 32 KiB |
| 单个出站 WebSocket | 每个隔离实例请求 1 个活动套接字 |

`isolated` 执行配置的正文上限比默认清单请求限额更严格。多个边界适用时取较小值。

## Component 边界

| 接口项 | 默认值 | 最大值 |
| --- | ---: | ---: |
| Component 产物 | — | 16 MiB |
| 线性内存 | 64 MiB | 64 MiB |
| 执行时间 | 30 秒 | 60 秒 |
| 输入/输出 | 1 MiB / 1 MiB | 1 MiB / 1 MiB |
| 保留的来宾错误 | — | 4 KiB |
| 宿主专用优化元数据 | — | 64 MiB |

限额通常按字节而非 Unicode 字符计算。调用能力前应拒绝或分块处理过大的输入，并且不要向不受信任的客户端直接暴露原生错误消息。
