状态： `partial`. 本页描述受支持的服务端子集，不涵盖完整浏览器规范。
下列清单以外的行为不属于支持契约。

权威来源： `runtime-js/web-api/compatibility.json`
(`tysel-server-web-subset`, stable).

## 支持

- ReadableStream 默认读取器与异步迭代
- WritableStream 写入器锁、ready 与串行写入
- TransformStream、pipeThrough 和 pipeTo，支持背压与 AbortSignal
- tee、取消与错误传播
- ByteLengthQueuingStrategy 和 CountQueuingStrategy

## 不支持

- HTTP 流式上传
- HTTP body 的 BYOB 读取器
- 宿主持有的外部缓冲区转移
- 流式 Body.clone

参阅 [JavaScript API 索引](/reference/javascript)和
[npm 兼容性指南](/docs/compatibility)。
