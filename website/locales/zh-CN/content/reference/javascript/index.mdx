Tysel 实现了一个有明确边界的服务端 Web API 执行配置。需要查询全局对象时使用这些页面；
需要完成具体工作流时，请使用[指南](/docs/guides)。

`partial` 表示列出的行为属于受支持约定，并不表示完整实现了对应的浏览器规范。
机器可读清单位于 `runtime-js/web-api/compatibility.json`。
