Tysel 实现了范围明确的服务端 Web API 子集。可通过这些页面查询全局 API，
具体工作流程请参阅[指南](/docs/guides)。

`partial` 表示列出的行为属于受支持的契约，并不代表完整实现了对应的浏览器规范。
机器可读清单位于 `runtime-js/web-api/compatibility.json`。
