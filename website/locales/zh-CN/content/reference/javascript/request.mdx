状态： `partial`. 本页描述受支持的服务端子集，不涵盖完整浏览器规范。
下列清单以外的行为不属于支持契约。

权威来源： `runtime-js/web-api/compatibility.json`
(`tysel-server-web-subset`, stable).

## 支持

- 字符串、ArrayBuffer 和 ArrayBufferView 请求体及响应体，读取时保留原始字节
- 只能读取一次的 json/text/arrayBuffer
- bodyUsed
- 缓冲请求和响应的 clone
- 宿主请求体和响应体的流式读取
- 收集字节后进行 UTF-8 解码，包括跨块码点与 BOM 处理
- Tysel 响应分块数组，对字符串、ArrayBuffer 和 ArrayBufferView 元素创建快照
- 按需创建 ReadableStream body，并跟踪锁定与读取状态
- Response 支持 Uint8Array 分块的 ReadableStream，以及原生背压和取消

## 不支持

- formData/blob 辅助方法
- 流式请求和响应的 clone
- 浏览器 cache、credentials 和 mode 语义

参阅 [JavaScript API 索引](/reference/javascript)和
[npm 兼容性指南](/docs/compatibility)。
