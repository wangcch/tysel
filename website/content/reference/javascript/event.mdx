# Event and EventTarget

Status: `partial`. This page is the supported server-side subset, not
the full browser specification. Behavior outside the lists below is not a
contract.

Source of truth: `runtime-js/web-api/compatibility.json`
(`tysel-server-web-subset`, stable).

## Supported

- function and object listeners
- listener deduplication and removal
- once and AbortSignal options
- preventDefault and immediate propagation stop

## Not supported

- DOM event trees
- capture and bubble phases
- browser exception reporting

See the [JavaScript API index](/reference/javascript) and the
[architecture notes](/docs/architecture/javascript-runtime-compatibility).
