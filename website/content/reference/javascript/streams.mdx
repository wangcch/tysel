Status: `partial`. This page is the supported server-side subset, not
the full browser specification. Behavior outside the lists below is not a
contract.

Source of truth: `runtime-js/web-api/compatibility.json`
(`tysel-server-web-subset`, stable).

## Supported

- ReadableStream default readers and async iteration
- WritableStream writer locks, ready and serial writes
- TransformStream, pipeThrough, pipeTo with backpressure and AbortSignal
- tee, cancellation and error propagation
- ByteLengthQueuingStrategy and CountQueuingStrategy

## Not supported

- HTTP streaming uploads
- HTTP body BYOB readers
- transfer of host-owned external buffers
- streamed Body.clone

See the [JavaScript API index](/reference/javascript) and the
[npm compatibility guide](/docs/compatibility).
